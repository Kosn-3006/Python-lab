# Python Lab

Мобильный интерактивный тренажёр Python.

## GitHub Pages
1. Создайте репозиторий `python-lab`.
2. Загрузите `index.html`.
3. GitHub → **Settings → Pages**.
4. **Deploy from a branch** → `main` → `/ (root)` → **Save**.
5. Ссылка будет вида `https://ВАШ-ЛОГИН.github.io/python-lab/`.

После публикации ученикам достаточно отправлять эту одну ссылку.
